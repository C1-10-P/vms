## Usage

Run migrations first for all tables to be added on the db
python manage.py makemigrations
python manage.py migrate

Create Super User
python manage.py createsuperuser
//eg admin@admin.com then access http://127.0.0.1:8000/admin to create Roles(Groups) and Permissions for your system users after running the server
python manage.py runserver

Adding Test Data

Seed database
python manage.py seed_db
python manage.py seed_db --action seed

Clean database
python manage.py seed_db --action clean

Reset database (clean then seed)
python manage.py seed_db --action reset

  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \

    "student_reg": "ENE221-0108/2018",
    "class_code": "TIE4101",
    "scan_method": "qr",
