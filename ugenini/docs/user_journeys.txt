Student Attendance Flow

1. Student presents QR code to ESP32-CAM
2. ESP32-CAM captures image, decodes QR → "ENE221-0108/2018|TIE4101"
3. Publishes MQTT: jkuat/attendance/class/sign_in
4. Mosquitto forwards to Django MQTT Client
5. handle_attendance_checkin() called
6. AttendanceService.process_api_check_in() executed
7. Validate student exists in database
8. Check for duplicate today
9. Create AttendanceSession → Validate → Complete
10. Save ClassAttendance record to PostgreSQL
11. Update Redis cache: attendance_today +1
12. Broadcast via WebSocket to dashboard
13. Dashboard updates real-time feed
14. ESP32-CAM receives success response, blinks LED

Visitor Check-in Flow

1. Visitor presents National ID to USB camera
2. Camera captures image, sends to OCR Service
3. OCR Service preprocesses image
4. Tesseract extracts text from ID
5. Regex patterns extract: Name, ID Number
6. VisitorSessionService.create_checkin_session()
7. Session created with status='awaiting_info'
8. Staff completes visitor info form
9. VisitorSessionService.complete_checkin_session()
10. Person and Visitor records created
11. VisitorVisit started with check_in_time
12. BLETag assigned to visitor
13. VisitorSession marked complete
14. ESP32-C3 starts tracking BLE tag
15. Real-time location updates begin
16. Dashboard shows visitor on map
